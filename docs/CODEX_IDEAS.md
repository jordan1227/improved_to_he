# Deferred Mod Ideas

Ideas recorded for later consideration; none are implemented merely by
appearing here. Each item should remain explicitly marked with status,
prerequisites, and last review date when it becomes an active planning item.

- **Deferred** — Poltergeist-charging artifact: an artifact that gains value or charge from nearby poltergeist/EMP exposure. This is intentionally separate from draining existing EMP-shield artifacts. Prerequisite: define the charge source and persistence model.
- **Deferred** — Standalone NVD equipment: when NVD is separated from outfits, move NVD-specific EMP resistance to the equipped NVD item rather than deriving it from armor or a global device tier. Prerequisite: establish the equipment owner and save/load contract.
- **Deferred** — Source-specific EMP presentation: optionally give Electras, electric poltergeists, and electro-chimera defensive bursts distinct audio/visual signatures while retaining the shared interference calculation. Prerequisite: inventory compatible effect assets.
- **Deferred** — EMP balance pass: tune the powerful-torch resistance and shared malfunction thresholds after testing simultaneous PDA, NVD, and flashlight behavior around each source type. Prerequisite: controlled runtime matrix.
