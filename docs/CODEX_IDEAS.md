# Deferred Mod Ideas

Ideas recorded for later consideration; none are implemented merely by appearing here.

- Poltergeist-charging artifact: an artifact that gains value or charge from nearby poltergeist/EMP exposure. This is intentionally separate from draining existing EMP-shield artifacts.
- Standalone NVD equipment: when NVD is separated from outfits, move NVD-specific EMP resistance to the equipped NVD item rather than deriving it from armor or a global device tier.
- Source-specific EMP presentation: optionally give Electras, electric poltergeists, and electro-chimera defensive bursts distinct audio/visual signatures while retaining the shared interference calculation.
- EMP balance pass: tune the powerful-torch resistance and shared malfunction thresholds after testing simultaneous PDA, NVD, and flashlight behavior around each source type.
