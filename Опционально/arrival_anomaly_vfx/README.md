# ARRIVAL Anomaly VFX/SFX

Merge this addon's `gamedata` folder over the main mod's `gamedata` folder to enable the ARRIVAL presentation-only anomaly port.

It contains the altered configs and the `semitone` particle, texture, and sound assets for Electra, Acidic/Fruit Punch, Springboard, Burner, and Whirligig. Gameplay settings are not changed.

The main mod intentionally retains `gamedata/lanims.xr` (the added light animation) and the three `sounds/monsters/poltergeist/polter_flame*.ogg` Zharka bolt-reaction sounds; they are shared base-mod content, not addon payload.
